Дурак: Выживание — как обновить сайт

1. Откройте репозиторий qwukato/chess-2 на GitHub.
2. Удалите старую папку docs (откройте её, три точки справа вверху -> Delete directory) и сделайте commit.
3. Нажмите Add file -> Upload files и перетащите на страницу ПАПКУ docs целиком (из распакованного архива, не zip). Нажмите Commit changes.
4. Подождите 1-2 минуты и откройте сайт. Если видите старую версию, обновите страницу дважды.

Правила Firestore менять не нужно: они те же, что и раньше (файл firestore.rules).
Аккаунты и чаты сохраняются.

APK: на pwabuilder.com вставьте адрес сайта и нажмите Package for stores -> Android.
